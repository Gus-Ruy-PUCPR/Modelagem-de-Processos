## 📌 Sobre o Repositório

Este repositório foi criado para armazenar, organizar e documentar as atividades desenvolvidas na disciplina de **Modelagem de Processos**, pertencente ao curso de **Engenharia de Software** da **Pontifícia Universidade Católica do Paraná (PUCPR)** — Campus Curitiba.

Ao longo do semestre, este espaço será utilizado para registrar as atividades práticas realizadas em sala de aula, exercícios, trabalhos e demais tarefas propostas pelo professor.

O objetivo é manter um histórico organizado do desenvolvimento das atividades e dos conhecimentos adquiridos durante a disciplina.
